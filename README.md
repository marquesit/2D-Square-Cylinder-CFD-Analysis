In this project, a CFD anlysis and validation of the flow past a 2D square cylinder was carried out at a Reynolds number (based on the cylinder's side L) of Re = 13000, 
an angle of attack of zero degrees and a side length ratio of 1.
This repo contains a report surrounding the simulations in the Ansys Fluent environmet, as well as a .rar/.zip file containing the most important files.
